::period{from="Jan" to="Jun"}
Teaching assistant for [Data Structures & Algorithms][cs-10] (CS 10).

This is the second intro course, taught in Java. It covers object-oriented design and the
standard data structures, like lists, trees, hash maps, and graphs. The problem sets use
them for things like webcam image processing, [Huffman
compression](/projects/information-theory/10-huffman-encoding), and [part-of-speech
tagging](/projects/ai/10-pos-tagging).
::

::period{from="May" to="Mar 2024"}
Researcher at the [Reality & Robotics Lab](https://rlab.cs.dartmouth.edu/home/), with
Alberto Quattrini Li.

Worked on deep learning and deep reinforcement learning for waterline detection on
autonomous boats.
::

::period{from="Jun" to="Aug"}
Teaching assistant for [Database Systems][cs-61] (CS 61).

The class covers relational databases, SQL, and transactions, then NoSQL systems like
MongoDB. When I took it, I built a [MySQL system for managing a journal's
submissions](/projects/systems/61-relational-app) and a [blog server on
MongoDB](/projects/systems/61-nosql-app).
::

::period{from="Sep" to="Nov"}
Teaching assistant for [Artificial Intelligence][cs-76] (CS 76).

It's an introduction to AI in Python, covering search, game playing, constraint
satisfaction, logic, and probabilistic reasoning. Each topic comes with a programming
assignment, like a [chess bot](/projects/ai/76-chess) that uses minimax with alpha-beta
pruning.
::

::period{from="Sep" to="Mar 2024"}
Teaching assistant for [Systems][cs-50] (CS 50).

Students write their own data structures in C, then use them to build a
[search engine](/projects/systems/50-tse) with a crawler, an indexer, and a querier. The
term ends with a team project, where groups share one Git repository and work with
git-flow to build a multi-user CLI game.
::
